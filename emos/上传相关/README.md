# 上传相关

上传分为 `视频 video` `字幕 subtitle` `图片 image` 等

分为4步 获取基本信息 -> 获取上传token -> 进行上传 -> 保存上传结果

## 子目录

- [视频](<视频/>)（4 个接口）
- [字幕](<字幕/>)（1 个接口）
- [图片](<图片/>)（2 个接口）
- [音乐](<音乐/>)（2 个接口）
- [分片上传](<分片上传/>)（4 个接口）
- [储存](<储存/>)（3 个接口）

## 接口

| 请求 | 方法 | 路径 |
| --- | --- | --- |
| [获取上传token](<获取上传token.json>) | `POST` | `/api/upload/getUploadToken` |
