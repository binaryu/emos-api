# 红包相关

红包
分为了几个维度 每个维度单独控制

# 红包类型

> 如何领取

- 普通红包 点击按钮领取
- 口令红包 回复正确内容领取
- 专享红包 只有特定的用户才可以领取

# 领取类型

> 红包的金额分配方式

- 均分模式 所有人都一样
- 随机模式 多少全凭运气

# 文件类型

> 这是一个什么样子的红包

- 图片 一张图 猜谜这种
- 音乐 一段音 猜歌这种

# 独占模式

> 这个红包在用户那里长什么样

如果是独占 只会显示文件 而没有寄语等什么

对于独占来说 可以自己设计红包封面等内容
